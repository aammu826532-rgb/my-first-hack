### Commands I learned today:

- `ls` - list all files and folders
- `ls folder1` - list inside a specific folder
- `cat folder1/passwords.txt` - read file content
- `cd /home/tryhackme` - go to home folder
- `grep flag access.log` - search word inside file
- `grep THM access.log` - search flag pattern
- `&&` - waits for first command to finish then runs next
- `>>` - saves output without overwriting file
