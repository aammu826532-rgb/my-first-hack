## 📝 What I Learned - Simple Notes

### 🌱 DAY 01 - How to WALK
- pwd -> Where am I?
- ls -la -> List all files
- cd -> Go to folder
- cat -> Read file
- mkdir / touch -> Create folder/file
- cp / mv / rm -> Copy/Move/Delete
- find -> Search file

*Concept:* Linux is all files daa!

### 🔥 DAY 02 - POWER TOOLS
- grep -> Search inside file (Ctrl+F)
- echo > & >> -> Write/Append
- chmod +x -> Give permission
- whoami / sudo -> Become admin
- ps aux -> Running apps
- | -> Pipe = Connect commands

*Concept:* Pipe is filter chain!

### 💀 DAY 03 - HACKER TOOLS
- gpg --import -> Verify file (blue tick)
- ss -tulpn -> See open ports
- awk '{print $1}' -> Cut first column
- sed 's/old/new/' -> Replace text (Y0u->You)
- xargs -> Conveyor belt
- sort | uniq -> Arrange & remove duplicate
- curl -O / wget -> Download from web
- xxd -> Hex hacker vision
- reset -> Clean terminal

*Final Flag:* Y0u C4n D0 It! = You Can Do It!
